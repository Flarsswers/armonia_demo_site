# Armonia Demo 案例字典

> 筛选标准：margin = S_target − S_source，即编辑后音频与 target / source prompt 的 CLAP 余弦相似度之差。margin 越大表示目标属性转移越成功。

> 生成时间：2026-09-24。对照音频目录：MusicDelta 见 `/DATA6_6T/yy/musicdelta_results`，MeloEdit 见 `/DATA6_6T/yy/exp_results_models`，SteerMusic 见 `/DATA1_4T/shared/AudioLDM2/A_ENM_Inversion/results/steermusic_reevaluation_20260924/`，NTI 见 `/DATA1_4T/shared/AudioLDM2/NTI/`。

> 说明：MusicDelta 的 source prompt 为该歌曲在 MusicDelta 数据集中的官方描述（captions_sources.csv 变体 1）；SteerMusic 在 MusicDelta 上为整曲编辑，已按「片段 N = 整曲第 (N-1)*10 秒起」裁剪到 10s 片段窗口（偏移关系经原生采样率逐样本验证，误差为 0），裁剪文件见 `steermusic_md_crops/`。
